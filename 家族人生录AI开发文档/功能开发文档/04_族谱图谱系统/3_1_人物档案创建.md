## 1. 功能概述

- 为家族成员创建独立的个人档案，包含基础信息和专属模块入口。创建后该成员出现在族谱中，可建立亲属关系。

## 2. 详细规格

### 2.1 触发条件

用户在族谱页点击“添加成员”按钮；或在老族谱OCR导入后确认创建草稿档案。

### 2.2 输入规范

姓名：必填，2-20字符
性别：必填，男/女/其他
出生日期：选填，年月日选择器
逝世日期：选填，年月日选择器（仅当状态为逝世时）
在世状态：必填，在世/逝世/失联/不详
辈分标签：选填，如“祖父辈”“父辈”“我辈”“子辈”
头像：选填，从相册选择或拍照
出生地：选填，省市区选择+详细地址
现居地：选填，省市区选择+详细地址
职业：选填，文本输入
学历：选填，下拉选择（小学/初中/高中/大专/本科/硕士/博士/其他）
生平简介：选填，最多500字，支持语音输入

### 2.3 处理规则

姓名校验：同一家族空间内，同名人物允许存在但需提示确认（可能是不同人）
日期校验：逝世日期不得早于出生日期；出生日期不得晚于当前日期
辈分自动推算：根据出生日期和已建立的亲属关系，可自动推荐辈分标签，用户可手动修改
档案初始化：创建成功后自动初始化空的人生时间线、采访素材库、个人相册、人生之书列表
创建者记录：记录档案创建人、创建时间，用于权限和审计
本人档案：用户首次创建家族空间后，引导创建自己的档案，标记为“本人”，本人档案数据本地存储

### 2.4 输出结果

创建成功：跳转至新创建的人物档案主页，显示引导提示“完善档案信息”
档案卡片：在族谱中显示该人物节点（姓名+辈分+头像）

### 2.5 异常处理

姓名为空：提示“请输入姓名”
日期逻辑错误：提示“日期填写有误，请检查”
同名提示：弹窗“家族中已有同名成员，确认要创建新档案吗？”
网络异常（共享档案）：保存到本地待同步队列，提示“档案已保存本地，将在联网后同步”

### 2.6 权限要求

超级管理员和授权编辑可创建任意成员档案；普通成员仅可创建自己的档案。

## 3. 依赖与关联

- **依赖功能**：F1.1,F1.3
- **关联功能**：F3.2,F3.3,F3.10,F3.11
- **涉及数据表**：person_profile
- **数据流说明**：添加成员 → 填写基础信息 → 校验 → 初始化空时间线/素材库/相册/人生之书列表 → 可建立亲属关系

## 4. AI 开发任务清单

- [ ] **任务1**：实现人物创建表单(姓名必填、性别必填、出生/逝世日期、在世状态、辈分、头像、出生地/现居地、职业、学历、生平简介)
- [ ] **任务2**：实现日期校验(逝世不早于出生、出生不晚于当前)、姓名校验、同名确认
- [ ] **任务3**：实现辈分自动推算与手动修改
- [ ] **任务4**：实现档案初始化(空时间线/素材库/相册/人生之书列表)与创建人记录
- [ ] **任务5**：实现'本人'档案标记与本地存储
- [ ] **任务6**：实现权限控制(管理员/授权编辑可创建任意，普通成员仅本人)

## 5. 验收标准与测试要点

- [ ] **验收1**：各字段校验生效(日期逻辑/必填/超长)
- [ ] **验收2**：同名人物提示确认后允许创建
- [ ] **验收3**：创建后自动初始化各专属模块空数据
- [ ] **验收4**：本人档案标记is_self且本地存储
- [ ] **验收5**：普通成员仅可创建自己档案
