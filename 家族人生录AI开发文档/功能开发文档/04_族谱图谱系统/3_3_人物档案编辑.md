## 1. 功能概述

- 修改人物档案的基础信息和专属模块内容。支持语音输入，适配中老年用户。编辑历史保留，可回溯。

## 2. 详细规格

### 2.1 触发条件

用户在人物档案主页点击“编辑”按钮。

### 2.2 输入规范

人物ID
待修改的字段及新值
编辑人用户ID

### 2.3 处理规则

字段级编辑：支持单独编辑每个字段，点击字段进入编辑态，无需整页编辑
语音输入：所有文本字段支持语音输入按钮，点击后语音识别填入
日期选择器：出生日期/逝世日期使用大号滚轮选择器，适配老人操作
地址选择：出生地/现居地使用省市区三级联动选择器
头像更换：支持拍照或从相册选择，提供圆形裁剪
生平简介：支持最多500字，实时字数统计，支持语音输入
编辑保存：保存时校验必填字段和逻辑约束，保存成功后更新展示
编辑历史：记录每次编辑的操作人、时间、修改字段和新旧值，管理员可查看编辑历史
冲突处理：多人同时编辑同一字段时，以最后保存为准，提示“该内容已被他人修改，请刷新后重新编辑”

### 2.4 输出结果

保存成功：返回档案主页，展示更新后的信息，提示“保存成功”
编辑历史页：展示时间倒序的编辑记录列表

### 2.5 异常处理

必填字段为空：提示“XX不能为空”
无权限编辑：提示“您没有权限编辑该成员档案”
字段超长：提示“XX不能超过XX字”
网络异常：保存到本地待同步，提示“已保存本地，将在联网后同步”

### 2.6 权限要求

超级管理员可编辑全部档案；授权编辑可编辑授权范围内的档案；普通成员仅可编辑本人档案。

## 3. 依赖与关联

- **依赖功能**：F3.1
- **关联功能**：F3.2
- **涉及数据表**：person_profile
- **数据流说明**：进入编辑 → 字段级编辑/语音输入/大号日期选择器 → 保存校验 → 记录编辑历史 → 冲突处理

## 4. AI 开发任务清单

- [ ] **任务1**：实现字段级编辑(点击字段进入编辑态)、语音输入所有文本字段
- [ ] **任务2**：实现大号滚轮日期选择器与省市区三级联动地址选择
- [ ] **任务3**：实现头像拍照/相册选择与圆形裁剪
- [ ] **任务4**：实现保存校验(必填/逻辑)与冲突处理(以最后保存为准并提示)
- [ ] **任务5**：实现编辑历史记录(操作人/时间/新旧值，管理员可查看)
