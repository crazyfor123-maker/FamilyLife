# 01 · 全局基础规范（公共底座）

> 本文件是整套 AI 分项开发包的**公共底座**。所有功能开发文档中出现的全局约束（权限/错误码/状态/UI/异常/数据字典）均以本文件为准。
> **请让每个参与开发的 AI 先读本文件，再读具体功能文档。**

---

## 1. 系统架构

### 1.1 三端架构
| 端 | 职责 | 核心能力 |
|---|---|---|
| 移动端APP | 用户交互主入口 | 语音采访、族谱展示、人生之书阅读、素材管理、本地AI推理 |
| 个人云服务器 | 家族共享数据存储与同步 | 成员数据同步、云端AI调用、共享素材存储、备份管理 |
| 本地离线端 | 个人私有数据本地存储 | 个人采访录音、个人档案、本地AI处理、离线工作 |

### 1.2 双AI模式架构（用户可一键切换）
- **云端AI模式**：联网调用公有大模型API，响应快、智能追问强；语音/文本需上传云端处理。
- **本地AI模式**：离线本地大模型运行，所有采访/转写/生成均在本地完成，不上传任何语音与文本，极致隐私；受设备性能限制。

### 1.3 双存储架构
- **本地存储**：当前登录用户本人所有数据（个人档案/自我采访录音/个人照片/人生之书草稿）全部本地留存，不上传云端。
- **云端存储**：家族内其他成员的公开档案、共享人生之书、家族大事记、时间墙、留言板存储于个人云服务器，实现家族成员同步查看。

## 3. 全局异常与错误处理规范

| 异常类别 | 处理策略 | 用户提示 |
|---|---|---|
| 网络断开 | 自动切离线模式，本地操作正常，联网后自动同步 | 当前网络不可用，已切换离线模式 |
| 云端服务器不可达 | 本地数据不受影响；重试（指数退避最多5次） | 家族服务器连接失败，请稍后重试 |
| AI服务调用失败 | 云端失败提示切本地；本地失败保存原始素材待重试 | AI服务暂时不可用，已保存您的录音 |
| 本地存储空间不足 | 提示清理，禁止覆盖已有数据 | 请清理不必要的素材后继续 |
| 录音权限被拒 | 引导到系统设置开启权限 | 请在设置中开启麦克风权限 |
| ASR转写失败 | 保留原始录音，标记失败，可手动重触发 | 原始录音已保存，可稍后重新转写 |
| 数据同步冲突 | 以时间戳最新为准，冲突保留双版本 | 请选择保留哪个版本 |
| APP崩溃 | 启动自动恢复上次状态，采访自动保存断点 | 已恢复您的采访进度 |

## 4. 中老年 UI 适配规范（全局横切）

| 维度 | 规范要求 |
|---|---|
| 字体大小 | 正文≥16sp，标题≥20sp，按钮文字≥18sp；提供「超大字体」模式(正文20sp) |
| 色彩对比度 | 正文与背景对比度≥4.5:1；提供「高对比度」模式 |
| 触控区域 | 可点击元素最小48dp×48dp；按钮间距≥8dp；关键按钮≥56dp高 |
| 弹窗控制 | 非必要不弹窗；大按钮+清晰文案+语音朗读；确认在右、取消在左 |
| 语音引导 | 核心流程支持语音引导；可开关「操作语音助手」 |
| 输入方式 | 优先语音输入，文本框提供麦克风按钮；适配大号键盘 |
| 导航设计 | 底部Tab≤4个，图标+文字双标识；返回按钮始终可见；面包屑显示位置 |
| 操作反馈 | 所有操作提供视觉+听觉双重反馈 |
| 防误操作 | 删除/不可逆操作二次确认；红色警示；关键操作可撤销(如删除5秒内) |
| 内容密度 | 留白充足，单屏信息块≤5个长文本段落 |
| 图标设计 | 简洁易懂，配文字说明，图标≥24dp |
| 朗读功能 | 所有长文本(人生之书/故事/大事记)支持AI朗读，可调音色语速 |
