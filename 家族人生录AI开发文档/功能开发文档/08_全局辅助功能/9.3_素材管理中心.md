# 功能开发文档：9.3 素材管理中心

| 项 | 值 |
|---|---|
| 功能编号 | 9.3 |
| 功能名称 | 素材管理中心 |
| 所属模块 | 模块七：全局辅助功能 |
| 优先级 | P1 |
| 建议工期 | 2.5天 |
| 涉及数据表 | —(素材文件) |

## 1. 功能概述

- 所有录音、图片、文档分类归档，支持标签分类、年代筛选、人物筛选，统一管理家族所有多媒体素材。

## 2. 详细规格

【素材分类】
按类型分为：采访录音、人物照片、老照片/历史照片、物件照片、人生之书(PDF)、备份文件、其他
【筛选功能】
按类型筛选、按关联人物筛选、按年代/年份筛选、按标签筛选
【搜索】
按文件名、标签、描述搜索素材
【素材详情】
文件信息（大小、格式、时长/尺寸、创建时间）、关联人物、关联内容（属于哪个采访/哪本书/哪个故事）、预览/播放
【素材操作】
重命名、添加标签、修改关联人物、移动分类、导出、删除（仅管理员）
【标签系统】
支持自定义标签，可为素材添加多个标签，按标签筛选和管理
【存储空间】
展示本地和云端存储使用情况，提供清理建议（重复照片、大文件）
【重复检测】
自动检测重复照片（基于内容哈希），提示用户清理重复
【素材引用】
显示素材被哪些内容引用（如某照片出现在哪本书哪个章节），删除引用中的素材时提示

## 3. AI 开发任务清单

- [ ] **任务1**：实现素材统一归档与类型分类（录音/照片/文档/备份等）
- [ ] **任务2**：实现按类型/人物/年代/标签筛选与文件名/标签/描述搜索
- [ ] **任务3**：实现素材详情展示与预览/播放
- [ ] **任务4**：实现素材操作（重命名/标签/关联人物/移动分类/导出/删除权限）与自定义标签系统
- [ ] **任务5**：实现存储空间展示、重复照片检测（内容哈希）与素材引用关系提示

## 4. 验收标准与测试要点

- [ ] **验收1**：素材按类型归档分类正确
- [ ] **验收2**：筛选与搜索生效
- [ ] **验收3**：素材详情与预览播放正常
- [ ] **验收4**：删除仅管理员，删除引用中素材有提示
- [ ] **验收5**：重复照片可检测并提示清理
