## 1. 功能概述

- 用户通过输入手机号和短信验证码完成登录，首次登录自动创建账号。全程极简操作，适配中老年用户，无复杂注册流程、无密码设置。

## 2. 详细规格

### 2.1 触发条件

用户打开APP，处于未登录状态；或用户在登录页主动触发登录操作。

### 2.2 输入规范

手机号：11位中国大陆手机号，格式校验通过
验证码：6位数字短信验证码，有效期5分钟
用户勾选《用户协议》和《隐私政策》（默认未勾选，需手动确认）

### 2.3 处理规则

手机号格式校验：正则校验11位、1开头，不合法时实时提示并禁止获取验证码
验证码发送：点击获取验证码后，60秒倒计时，期间按钮置灰；同一手机号每天最多发送10条验证码
验证码校验：比对服务端下发的验证码，错误3次后锁定该手机号15分钟
首次登录自动注册：手机号未绑定账号时，自动创建新用户账号，无需额外注册步骤
登录态持久化：登录成功后生成Token，本地加密存储，有效期30天

### 2.4 输出结果

登录成功：跳转至家族空间列表页（已有空间）或创建家族引导页（无空间）
登录失败：在当前页显示具体错误原因（验证码错误/手机号格式错误/网络异常）
首次登录：显示欢迎引导页，介绍APP核心功能

### 2.5 异常处理

手机号格式错误：实时红字提示“请输入正确的手机号”，获取验证码按钮不可点击
验证码发送失败：提示“验证码发送失败，请稍后重试”，保留60秒倒计时
验证码错误：提示“验证码错误，请重新输入”，清空验证码输入框
验证码过期：提示“验证码已过期，请重新获取”
网络异常：提示“网络连接失败，请检查网络后重试”
账号被锁定：提示“操作过于频繁，请15分钟后再试”

### 2.6 权限要求

所有用户均可使用，无角色限制。

## 3. 依赖与关联

- **依赖功能**：无
- **关联功能**：F1.2 自动登录
- **涉及数据表**：user_account
- **数据流说明**：手机号+验证码登录 → 首次自动注册账号 → 生成登录Token(30天) → 跳转空间列表或创建引导页

## 4. AI 开发任务清单

- [ ] **任务1**：实现手机号格式校验(11位、1开头)，非法时实时提示并禁止获取验证码
- [ ] **任务2**：实现短信验证码发送接口：60秒倒计时、同一手机号每日最多10条
- [ ] **任务3**：实现验证码校验：错误3次锁定该手机号15分钟；验证码有效期5分钟
- [ ] **任务4**：实现首次登录自动注册账号逻辑
- [ ] **任务5**：实现登录Token生成与本地加密存储(有效期30天)
- [ ] **任务6**：实现登录成功跳转(有空间→空间列表；无空间→创建引导页)及首次登录欢迎引导页
- [ ] **任务7**：实现用户协议/隐私政策勾选校验

## 5. 验收标准与测试要点

- [ ] **验收1**：手机号格式错误实时红字提示且获取验证码按钮不可点
- [ ] **验收2**：验证码错误3次后锁定15分钟并提示
- [ ] **验收3**：首次登录自动创建账号，无需额外注册
- [ ] **验收4**：登录成功生成Token且本地加密存储，有效期30天
- [ ] **验收5**：无家族空间的用户登录后进入创建家族引导页
- [ ] **验收6**：验证码发送失败/过期/网络异常均有对应提示
