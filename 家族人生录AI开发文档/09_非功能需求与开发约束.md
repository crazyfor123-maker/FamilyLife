# 09 · 非功能需求与开发约束

> 本文档汇总全局非功能需求（性能/安全/兼容/可用性/备份恢复）及 MVP 排期与模块依赖，作为所有功能开发的横切约束与排期依据。

---

## 1. 性能需求

| 性能指标 | 要求 |
|---|---|
| APP启动时间 | 冷启动≤3秒（中端机型），热启动≤1秒 |
| 页面加载时间 | 主要页面≤2秒（有缓存≤0.5秒） |
| 族谱渲染 | 100人内≤1秒；500人内≤3秒；超500人懒加载 |
| 语音采访延迟 | 云端：AI提问<1秒、ASR实时<500ms；本地：<3秒 |
| 人生之书生成 | 1万字内≤30秒（云端），超1万按比例增加，提供进度 |
| PDF导出 | 100页内≤15秒，超100页按比例增加 |
| 图片加载 | 缩略图≤500ms，原图≤3秒（WiFi） |
| 搜索响应 | 全局搜索≤500ms（本地索引），云端≤2秒 |
| 同步性能 | 100条增量同步≤10秒；大文件断点续传 |
| 内存占用 | 运行≤500MB（族谱渲染峰值≤800MB） |
| 电量消耗 | 语音采访1小时电量消耗≤15% |

## 2. 安全与隐私需求

- **数据加密**：本地 AES-256 加密（密钥由设备硬件安全模块管理）；云端传输 TLS1.3；云端存储用户自定义密钥加密。
- **身份认证**：手机号验证码登录；Token 有效期30天；支持远程登出；敏感操作（删除/导出/转让管理员）需短信二次验证。
- **数据隔离**：家族空间间完全隔离；个人私有数据与家族共享数据物理/逻辑隔离；不同用户本地数据隔离。
- **AI隐私**：采访原始数据不参与任何模型训练；云端AI调用选择支持「不用于训练」的API；本地AI模式数据不出设备。
- **权限控制**：基于角色的访问控制（RBAC），写操作校验权限，读操作按权限过滤。
- **操作审计**：记录敏感操作（删除/导出/权限变更/成员管理）的操作人/时间/内容，管理员可查审计日志。
- **数据备份**：全量离线备份，备份文件可加密；用户完全拥有数据，可随时导出迁移。
- **防数据丢失**：原始录音和原图永久保存不覆盖；多版本管理；自动保存草稿；本地+云端双存储。
- **应用安全**：代码混淆、防篡改检测、越狱/Root 风险提示、敏感信息不写日志。
- **合规**：符合《个人信息保护法》《数据安全法》；用户协议和隐私政策明确告知；可注销账号和删除数据。

## 4. 可用性 & 数据备份恢复需求

**可用性**
- APP核心功能（采访/族谱/人生之书）可用性≥99.5%；云端服务≥99%。
- 故障恢复：崩溃自动恢复状态；云端故障本地功能不受影响；同步故障自动重试。
- 容灾备份：云端每日自动备份，保留30天；用户可手动全量备份。
- 用户支持：帮助中心/FAQ/操作引导/反馈入口；关键流程新手引导。
- 可访问性：屏幕阅读器（TalkBack/VoiceOver）、色彩无障碍、字体放大、语音操作。

**数据备份与恢复**
- 自动备份：云端每日增量备份保留30天；本地数据 WiFi+充电时自动备份到本地。
- 手动全量备份：超级管理员一键导出全量数据包（JSON+录音+原图+文档），可加密。
- 备份存储：本地文件系统、可导出U盘/电脑/云盘，不强制存APP服务商。
- 完整性校验：备份文件生成MD5，恢复时校验。
- 恢复能力：完整恢复到新设备/新空间，支持选择性恢复。
- 数据迁移：支持家族空间从一个云服务器迁移到另一个。
- 版本兼容：备份格式向前兼容。

## 5. MVP 排期与模块依赖

### 5.1 第一期核心模块（MVP 闭环）
目标：跑通完整闭环——创建家族→录入族谱→AI采访→生成人生之书→导出打印。

| 模块 | 功能点 | 优先级 | 依赖模块 | 预计工期 |
|---|---|---|---|---|
| 账号与家族空间 | F1.1~F1.10 全部 | P0 | 无 | 2周 |
| 双存储隐私架构 | F2.1~F2.5 | P0 | 账号 | 2周 |
| 族谱图谱 | F3.1~F3.3、F3.10~F3.17 | P0 | 账号+存储 | 3周 |
| AI语音采访 | F4.1~F4.11 | P0 | 账号+存储+人物档案 | 4周 |
| AI人生之书 | F5.1~F5.3、F5.5、F5.7~F5.8 | P0 | 采访+人物档案 | 3周 |
| 全局辅助 | 9.1 搜索、9.2 离线(基础)、9.4 UI | P0 | 全部 | 1周 |

第一期总工期约 15 周（可并行，关键路径约 12 周）。

### 5.3 模块依赖关系
- 核心依赖链路：账号(F1) → 双存储(F2) → 族谱(F3) → AI采访(F4) → 人生之书(F5) → PDF导出。
- 账号 → 家族特色功能(F6 时间墙/大事记/留言板)。
- 族谱(人物档案) ←→ AI采访(采访对象) ←→ 人生之书(素材来源) 形成核心数据闭环。
- 双存储为所有模块提供存储与同步基础。
- 全局辅助功能（搜索/离线/UI）横切所有模块。
