# 功能开发文档：9.1 全局搜索

| 项 | 值 |
|---|---|
| 功能编号 | 9.1 |
| 功能名称 | 全局搜索 |
| 所属模块 | 模块七：全局辅助功能 |
| 优先级 | P0 |
| 建议工期 | 2天 |
| 涉及数据表 | 全表 |

## 1. 功能概述

- 支持搜索人名、故事关键词、年份、事件、留言、采访内容等，快速定位任意家族记忆内容。搜索结果受用户权限过滤。

## 2. 详细规格

【搜索范围】
人物姓名、人物档案简介、时间线事件标题/内容、时间墙故事标题/内容、家族大事记标题/内容、留言板内容、采访转写文本、人生之书章节标题/内容、关系备注
【搜索方式】
顶部搜索框，支持关键词输入和语音输入搜索
【结果展示】
- 搜索结果按类型分组展示（人物/故事/大事记/留言/采访/人生之书），每组最多5条，可点击「查看更多」
- 搜索历史：保留最近10条，可点击快速搜索，可清除历史
- 输入时实时展示搜索建议（匹配的人名、关键词）
- 匹配关键词高亮显示
- 支持搜索特定年份（如「1980」），返回该年所有事件和故事
- 无结果时显示「未找到相关内容」，并推荐热门搜索
【权限过滤】
搜索结果仅返回当前用户有权限查看的内容，无权限内容不出现

## 3. AI 开发任务清单

- [ ] **任务1**：建立本地搜索索引，覆盖全部可搜索内容类型
- [ ] **任务2**：实现顶部搜索框（关键词输入+语音输入）
- [ ] **任务3**：实现结果按类型分组展示（每组≤5条+查看更多）、关键词高亮
- [ ] **任务4**：实现搜索历史（保留10条/清除）与实时搜索建议、年份搜索
- [ ] **任务5**：实现搜索结果权限过滤与空结果/热门搜索推荐

## 4. 验收标准与测试要点

- [ ] **验收1**：覆盖文档列出的全部搜索范围
- [ ] **验收2**：结果按类型分组且关键词高亮
- [ ] **验收3**：搜索历史与建议正常
- [ ] **验收4**：年份搜索返回对应事件故事
- [ ] **验收5**：无权限内容不出现在结果中

## 5. 全局规范衔接提示

- **UI 适配**：遵循中老年 UI 规范。
