## 1. 功能概述

- 管理人物的所有AI语音采访素材，包括原始录音、ASR转写文本、采访片段。支持播放、编辑、关联到人生之书。

## 2. 详细规格

### 2.1 触发条件

用户在人物档案主页切换到“采访素材”标签页。

### 2.2 输入规范

人物ID
采访会话列表
用户权限

### 2.3 处理规则

素材分类：按采访会话分组，每个会话显示：采访日期、时长、提纲主题、转写状态
原始录音：永久保存原始录音文件，支持在线播放（本人本地播放/他人云端流式播放）
ASR转写：展示实时转写的文本内容，按问答分段，支持编辑修正转写错误
转写状态：未转写/转写中/转写成功/转写失败，失败可手动重新触发
采访片段：支持从转写文本中选中一段，标记为“精彩片段”，可关联到人生之书对应章节
素材搜索：支持按关键词搜索转写文本内容
素材导出：支持导出单段采访的录音和文本
本人素材：本人采访素材本地存储，离线可查看和播放
他人素材：他人采访素材需授权后可查看，从云端加载

### 2.4 输出结果

展示采访会话列表，点击进入单场采访详情页
采访详情页：顶部录音播放器 → 下方问答式转写文本（AI提问灰色/用户回答黑色） → 每段可标记精彩片段
提供“发起新采访”按钮

### 2.5 异常处理

录音播放失败：提示“录音播放失败，请检查网络”（他人素材）或“录音文件损坏”
转写失败：显示“转写失败”标签，提供“重新转写”按钮
无权限：提示“您没有权限查看该成员的采访素材”

### 2.6 权限要求

本人素材本人可完全管理；他人素材需超级管理员授权查看/编辑。

## 3. 依赖与关联

- **依赖功能**：F3.1,F4.9
- **关联功能**：F4.10,F4.11
- **涉及数据表**：interview_session,interview_qa
- **数据流说明**：按采访会话分组 → 展示录音/转写 → 播放/编辑/标记精彩片段 → 关联人生之书

## 4. AI 开发任务清单

- [ ] **任务1**：实现采访素材按会话分组列表(日期/时长/提纲/转写状态)
- [ ] **任务2**：实现原始录音播放(本人本地播放/他人云端流式)
- [ ] **任务3**：实现ASR转写文本问答式分段展示与编辑修正
- [ ] **任务4**：实现转写状态管理(未转写/转写中/成功/失败，失败可重触发)
- [ ] **任务5**：实现'精彩片段'标记与素材搜索/导出

## 5. 验收标准与测试要点

- [ ] **验收1**：素材按会话分组展示
- [ ] **验收2**：本人素材本地播放，他人素材需授权云端加载
- [ ] **验收3**：转写文本可编辑修正，状态可管理
- [ ] **验收4**：片段可标记精彩并关联人生之书
- [ ] **验收5**：无权限查看他人素材被拦截
