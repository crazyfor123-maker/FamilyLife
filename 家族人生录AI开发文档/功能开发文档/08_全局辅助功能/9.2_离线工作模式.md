# 功能开发文档：9.2 离线工作模式

| 项 | 值 |
|---|---|
| 功能编号 | 9.2 |
| 功能名称 | 离线工作模式 |
| 所属模块 | 模块七：全局辅助功能 |
| 优先级 | P0 |
| 建议工期 | 2天 |
| 涉及数据表 | sync_queue |

## 1. 功能概述

- 无网络时可正常录音采访、本地存储、查看已缓存数据，联网后自动同步转写、AI生成、上传共享数据。

## 2. 详细规格

【离线检测】
实时检测网络状态，无网络时顶部显示「离线模式」标识
【离线可用功能】
① 本人采访录音（本地存储） ② 查看已缓存的族谱、人物档案、人生之书 ③ 查看已缓存的时间墙、大事记、留言 ④ 本地AI模式全功能 ⑤ 编辑本人档案（本地保存待同步）
【离线不可用功能】
① 云端AI模式（TTS/ASR/追问/生成） ② 查看未缓存的他人共享数据 ③ 同步上传 ④ PDF导出（需云端排版时）
【离线队列与同步】
- 离线时的写操作（发布故事、编辑档案、留言等）进入本地待同步队列
- 网络恢复后自动同步离线队列数据，按时间顺序上传，同步进度可在设置查看
- 同步冲突以时间戳最新为准，冲突保留双版本供选择
- 自动缓存最近访问数据，可查看缓存大小和清理
- 用户尝试离线不可用功能时提示「当前无网络，该功能需联网使用」

## 3. AI 开发任务清单

- [ ] **任务1**：实现网络状态实时检测与「离线模式」顶部标识
- [ ] **任务2**：实现离线可用/不可用功能清单的开关控制
- [ ] **任务3**：实现离线写操作进入本地待同步队列
- [ ] **任务4**：实现网络恢复自动同步、同步冲突处理与缓存管理
- [ ] **任务5**：实现尝试离线不可用功能时的提示
