## 1. 功能概述

- 全局UI设计遵循中老年适配规范，确保产品对中老年用户友好易用。本功能为全局横切规范，需贯穿所有功能模块落地。

## 2. 详细规格

【字体大小】
正文不小于16sp，标题不小于20sp，按钮文字不小于18sp；提供「超大字体」模式（正文20sp）
【色彩对比度】
正文与背景对比度不低于4.5:1；避免浅灰、低饱和色作关键信息；提供「高对比度」模式
【触控区域】
所有可点击元素最小48dp x 48dp；按钮间距不小于8dp；关键操作按钮不小于56dp高度
【弹窗控制】
非必要不弹窗；必须弹窗时大按钮+清晰文案+语音朗读选项；确认按钮在右、取消在左
【语音引导】
核心操作流程支持语音引导提示；可在设置中开启/关闭「操作语音助手」
【输入方式】
优先语音输入，所有文本输入框提供麦克风按钮；文字输入适配大号键盘
【导航设计】
底部Tab不超过4个，图标+文字双标识；返回按钮始终可见且足够大；面包屑导航显示当前位置
【操作反馈】
所有操作提供视觉+听觉双重反馈；成功/失败有明确提示音和文字；加载状态有动画和文字说明
【防误操作】
删除/不可逆操作二次确认；确认弹窗红色警示按钮；关键操作有「撤销」机会（如删除后5秒内可撤销）
【内容密度】
页面内容留白充足，避免信息过载；单屏信息块不超过5个长文本段落；列表项间距充足
【图标设计】
图标简洁易懂，避免抽象符号；关键功能图标配文字说明；图标大小不小于24dp
【朗读功能】
所有长文本内容（人生之书、故事、大事记）支持AI朗读；朗读可调节音色和语速

## 3. AI 开发任务清单

- [ ] **任务1**：落地全局字体/对比度/触控区域规范与「超大字体」「高对比度」模式
- [ ] **任务2**：规范弹窗（大按钮/语音朗读/确认右取消左）与防误操作（二次确认/红色警示/撤销）
- [ ] **任务3**：落地语音引导、优先语音输入（麦克风按钮）、大号键盘
- [ ] **任务4**：落地导航（底部≤4Tab/返回始终可见）与操作双重反馈
- [ ] **任务5**：落地内容密度/图标规范与长文本AI朗读能力

## 4. 验收标准与测试要点

- [ ] **验收1**：全局界面符合字体/对比度/触控规范
- [ ] **验收2**：超大字体与高对比度模式可用
- [ ] **验收3**：弹窗与防误操作符合规范
- [ ] **验收4**：语音引导与语音输入可用
- [ ] **验收5**：长文本支持AI朗读

## 5. 全局规范衔接提示

- **权限**：本功能受全局权限矩阵约束。
- **UI 适配**：遵循中老年 UI 规范。
